# Guide

Using this section, you can step by step, with simple instructions,
set up the security of your systems.

## Prerequisites

### Operating Systems

To follow the recommendations on the site, it is necessary to update to the latest
versions of operating systems:

:material-microsoft-windows: Windows 11

:material-apple: MacOS Sonoma 14

:material-android: Android 14

:material-apple-ios: iOS 17

### Windows Settings


For Windows, the Pro or Enterprise edition is required. [;)](https://github.com/massgravel/Microsoft-Activation-Scripts){:target="_blank"}


### Backups

The instructions include Data Encryption. In case of errors or software bugs, 
there is a risk of data loss. Therefore, before encrypting data, it is necessary to
create backups of particularly important data.


## System Profile Installation

FOI Security Policy system profile collections will automatically configure most settings.
