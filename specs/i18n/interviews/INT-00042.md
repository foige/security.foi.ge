# INT-00042: English Translation of FOI Security

## Summary

Full English translation of the FOI Security site. AI-generated with human review.
The English version mirrors the Georgian original, with explicit records of any
Georgia-specific content that is removed or adapted for the international audience.

## Interview Claims

### Anchors

- [USR-00043] [goal] Every page on the site gets an English translation. Full scope — solutions, policies, tools, about pages. No partial rollout.

- [USR-00044] [goal] English content is a 1:1 structural mirror of Georgian. Same pages, same sections, same flow. Divergence is only for Georgia-specific content, and every such divergence is explicitly recorded.

- [USR-00045] [hard_constraint] Translation is AI-generated with human review. The AI produces the draft; a human approves it. No AI-generated content goes live without human sign-off.

- [USR-00046] [hard_constraint] Georgia-specific content (laws, partnerships, latency recommendations, cultural references) is removed or adapted in the English version, with an explicit record of each removal/adaptation and its rationale.

### Negotiable

- [USR-00047] [tentative_solution] Use mkdocs-static-i18n plugin with file suffix approach: `passwords.md` (Georgian default) + `passwords.en.md` (English). Least disruptive to current structure.

- [USR-00048] [preference] The English translation must preserve the original tone — direct, opinionated, no jargon without explanation, no sugar-coating. Tonal parity matters as much as factual accuracy.

- [USR-00049] [fact] The password generator already has English wordlists (`foi_words_en.txt`, `foi_syllables_en.txt`). The generator UI text needs translation but the underlying tool is already bilingual.

- [USR-00050] [fact] Policy files (.mobileconfig, GPO scripts) are language-agnostic — they configure system parameters, not user-facing text. Policy documentation pages need translation; the policy files themselves do not.

- [USR-00051] [open_question] Terminology glossary — what are the canonical English equivalents for Georgian security terms used throughout the site? This needs to be established before translation begins to ensure consistency.

- [USR-00052] [open_question] What happens to the about page's Georgian-specific narrative (სირცხვილია partnership, Digital Defenders, Georgian law context) in the English version? Full removal, or reframed for international context?

## Research Notes

- mkdocs-static-i18n plugin supports file suffix approach: `file.md` (default) + `file.en.md` (translated). Config in mkdocs.yml sets default_language and available languages. Material theme auto-generates language switcher.
- 27 markdown files in docs/ need translation. Several include-markdown files (5 in `includes/`) also need English variants.
- Video examples are hosted on security-media.foi.ge with Georgian narration/UI — these won't be translated. Video references in English pages need handling.
- The about/trainers.md page references Georgian-specific pedagogy context but the principles are universal.
- About page references სირცხვილია (Shame movement), Digital Defenders, Georgian "Russian law" — these are Georgia-specific.
- VPN page recommends German servers with Georgia-specific latency reasoning (50-60ms from Georgia).
- CLI tools have Georgian transliterated menu items (e.g., "PIN Kodit Shesvlis Idzuleba") — tool UI is a separate concern from docs translation.

## Clarifications

- Q: Full translation or subset first? A: Full.
- Q: Who translates? A: AI-generated with human review.
- Q: 1:1 mirror or adapted? A: Mirror with explicit records of Georgia-specific removals.
